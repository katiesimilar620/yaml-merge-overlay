## 🧰 What yaml-merge-overlay Does

yaml-merge-overlay helps you update one YAML file with changes from another YAML file without manually copying and pasting sections. A YAML file is a structured text file often used for settings and configuration. Instead of replacing the whole base file, the overlay is applied on top of it.

The result is a new merged file. Your original base file and overlay file stay as they are, so you can review the output before using it.

Common uses include:

- Updating a base settings file with environment-specific changes.
- Combining a standard configuration with a local override.
- Applying a small set of changes across a larger YAML document.
- Keeping nested sections together instead of replacing entire blocks.
- Producing a clean merged file for review or sharing.

The utility is built around one simple task: deep-merge a YAML overlay onto a base file and write the result.

## 🪄 How the Merge Works

Think of the base file as your starting document and the overlay as a set of instructions for what should change.

When both files contain the same top-level setting, the overlay value is used. When both files contain the same nested section, yaml-merge-overlay goes deeper and combines the values inside that section. Values that appear only in the base file remain in the result. Values that appear only in the overlay file are added to the result.

A simple way to picture it:

- Base file: contains your normal settings.
- Overlay file: contains only the settings you want to change.
- Merged file: contains the normal settings plus the overlay changes.

This is useful when you want to keep most of a file the same but adjust a few values. Deep merging means the tool does not simply replace a whole section when only one value inside it changes.
